# Classes

Every Crawler picks a class at Level 1. Each class has a favorite Move Call: +1 to rolls for that Move Call in every dance-off. Each class branches into hybrid classes at Level 10.

| Class | Favorite Move Call | Fantasy |
|---|---|---|
| Amphibious Breacher | Endurance | Doors, walls and beach landings. Cordula's class |
| Benthic Dragoon | Choreography | A deep-water caster who fights with light and ink. Barnaby's class |
| Kayak Patrol Ranger | Footwork | At home on any water; scouts ahead of the party |
| Ferry Engineer | Power | Keeps the ferry running, repairs broken gear |
| Ballard Brewer | Presence | Brews potions from any ingredient on the floor |
| Fish-Toss Striker | Footwork | Throws fish, crates and coins with frightening accuracy |
| Grunge Bard | Presence | Loud, sincere, slightly out of tune on purpose |
| Coffee Alchemist | Choreography | Turns beans into buffs |
| Salvage Artificer | Choreography | Builds gear out of debris |
| Rain Warden | Read the Room | Reads the weather and the crowd |
| Floating-Bridge Engineer | Endurance | Holds structures together under impossible loads |
| Startup Necromancer | Presence | Raises dead projects and pitches them again |

Level 10 hybrid paths include Tidewall Breacher (Amphibious Breacher) and Abyssal Choreographer (Benthic Dragoon).

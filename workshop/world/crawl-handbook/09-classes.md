# Classes

Every Crawler picks a class at Level 1. Each class has a favorite Move Call: +1 to rolls for that call in every dance-off. Classes branch into hybrid classes at Level 10.

| Class | Favorite Move Call | Fantasy |
|---|---|---|
| Amphibious Breacher | Endurance | Doors, walls and beach landings. Cordula's class |
| Benthic Dragoon | Choreography | A deep-water caster who fights with light and ink. Barnaby's class |
| Kayak Patrol Ranger | Footwork | At home on any water, scouts ahead |
| Ferry Engineer | Power | Keeps things running, fixes the unfixable |
| Ballard Brewer | Presence | Brews potions from whatever the floor offers |
| Fish-Toss Striker | Footwork | Throws things with frightening accuracy |
| Grunge Bard | Presence | Loud, sincere, slightly out of tune on purpose |
| Coffee Alchemist | Choreography | Turns beans into buffs |
| Salvage Artificer | Choreography | Builds gear out of debris |
| Rain Warden | Read the Room | Reads the weather and the crowd |
| Floating-Bridge Engineer | Endurance | Holds things together under impossible loads |
| Startup Necromancer | Presence | Raises dead projects and pitches them again |

Hybrid paths at Level 10 include Tidewall Breacher (Amphibious Breacher) and Abyssal Choreographer (Benthic Dragoon).

# Theme textures

- `obsidian-512x512.webp`: dark obsidian stone with faint violet veins, rendered with Muse Image (request in `images/src/tex-obsidian.request.json` at the repo root); the theme applies the texture to panel and form backgrounds

If a texture file is missing, the Floor 6 web interface theme falls back to the solid colors (`--color-parchment`, `--color-wood-dark`).
